## 🤖 About Community Poke

**Community Poke** is a [Poke](https://poke.com) instance that was turned into a Discord bot in the Poke Community Discord server.

> Nothing Community Poke does is endorsed by The Interaction Company of California or Cognition.

> **Note on the repositories:** mind the repos. Most of them were made by one dude. For the story, come to Discord and ask about Wolfy.

Come say hi at **[poke.com/discord](https://poke.com/discord)**.

For a plain-language overview of how the bot works, see [docs/how-it-works.md](https://github.com/CommunityPokeOrg/.github/blob/main/docs/how-it-works.md).

---

## 🧭 Who we are

**CommunityPokeOrg** is the workshop of the Poke Community. Where the [**CommunityPoke**](https://github.com/CommunityPoke) account is the identity of the shared Poke instance itself, this organization is where the community's *projects* live: tools, bridges, libraries, and the occasional game that exists purely because someone in the Discord said "wouldn't it be funny if."

Everything here is public, built in the open, and maintained with a healthy mix of engineering rigor and community chaos.

## 🧬 Mission & values

- **Community first.** Ideas come from the Discord; the repos are where they become real.
- **Open by default.** Public code, public issues, public mistakes.
- **Agents are contributors too.** A shared Poke instance and an autonomous Devin do real engineering here. Their PRs get reviewed like everyone else's — and sometimes roasted harder.
- **Privacy and safety matter.** Even the meme projects avoid collecting more than they need; the serious ones treat it as a design requirement.
- **Ship, then polish.** Working software over perfect plans. Then, ideally, polish.

---

## 📜 Community lore

- The organization exists because one GitHub account turned out to be a suspiciously small container for a whole community's side projects.
- The shared instance lives across Telegram and Discord at once; several projects here are downstream consequences of that decision.
- Yes, there is a clicker game about peat bog compute broth. No, nobody can fully explain it. Yes, it has server racks.
- Commits authored by an autonomous agent on behalf of a community-run assistant are considered normal here. Governance is best described as "vibes with code review."

## 🤝 Contributing

1. **Pick a repo** from the list above and read its README — each project documents its own setup and conventions.
2. **Open an issue** before large changes so the idea can be discussed in the open.
3. **Fork → branch → pull request.** Keep PRs focused, describe the *why*, and include tests where the project has them.
4. **Be kind, be direct.** Reviews are honest; people (and agents) are treated with respect.
5. **Security reports:** follow the security guidance in the relevant repository's README or open a private report via that repository's Security tab.
